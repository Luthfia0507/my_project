Projek ini adalah website sistem informasi produk make-up dan skincare.
pada website tersebut terdapat tabel informasi produk. memuat seperi id, nama, kategori, harga, stok sampai deskripsi produk.
pada projek tersebut terdapat logika conditional yanag dimana setiap stok kurang dari 2, akan otomatis muncul kritis dan warna tabel akan menjadi merah sebagai peringatan.
